# 圓弧必要條件剪枝

**歷史狀態**　僅供診斷

## 問題

希望在昂貴的多弧求解前安全排除一批候選半徑。

## 程式與合成對照

若兩點離圓周最多 e，兩點弦長 d 至多為 2(r+e)，所以 r 至少為 d/2−e。範例量到兩個必拒候選。

```shell
dotnet src/Cli/bin/Release/net10.0/Cli.dll experiment run necessary-bound
```

輸出 `observations` 列出判定依據，`reproduced` 表示合成對照是否符合預期。 [實作](../../src/Core/Experiments.cs#L119)

## 後續去向

歷史專案保留精確必要條件、原序支持與證書核對。通過必要條件的候選仍需有限弧、相切及位置驗證。

[回方案索引](../engineering-decisions.md)

## 設計假設、失效條件與留下的技術

| 問題 | 設計判斷 |
| --- | --- |
| 什麼條件下有效 | 用可證必要條件提前排除不可能的候選，降低求解量。 |
| 反例暴露什麼 | 通過必要界不表示充分可行，數值求解仍須完成；預算未跑完不能記無解。 |
| 後續怎麼處理 | 保留剪枝理由與正例回放，不把剪枝通過當正式幾何解。 |

以上是歷史方法的適用邊界與現行去向。此頁命令實跑獨立最小反例，原公司程式與原資料留本機；缺少紀錄的淘汰原因不補推測。

## 現行工程草稿中的角色

安全剪枝可減少不必要的求解，通過必要條件卻不保證有用輪廓。工程草稿不以前置完成全部精確模型搜尋作門檻，保留此工具作求解診斷。 [現行交付判準](../engineering-acceptance.md)。
