# 配對中點與中心線

**歷史狀態**　部分沿用

## 問題

給定同支兩條側線，希望用中點建立剖框中心導引。

## 程式與合成對照

舊工具有按索引和索引偏移配對的版本。公開例給兩側不同取樣密度，對照按索引及以弧長對齊時的中心末端。

```shell
dotnet src/Cli/bin/Release/net10.0/Cli.dll experiment run paired-center
```

輸出 `observations` 列出判定依據。 [實作](../../src/Core/Experiments.cs#L233)

## 後續去向

中心線用途保留。短支及末端位置增加本支兩界、站位及方向核對。單靠索引配對無法驗證分支身分。


## 設計假設、失效條件與留下的技術

| 問題 | 設計判斷 |
| --- | --- |
| 什麼條件下有效 | 兩側有可靠同站配對時，中點可形成平穩導引。 |
| 反例暴露什麼 | 中點不是任何一側原表面；配對錯誤會移動中心，不能當去焊道觀測。 |
| 後續怎麼處理 | 保留參考中心用途，原支持身分另核。 |

以上是歷史方法的適用邊界與現行去向。此頁命令實跑獨立最小反例，原公司程式與原資料留本機；缺少紀錄的淘汰原因不補推測。

## 現行工程草稿中的角色

中心／導引可減少定位準備，但工程面需要側邊主要輪廓，不能直接用中點替代。此技術作輸入輔助，幾何用途與最終貼面分開。 [現行交付判準](../engineering-acceptance.md)。
