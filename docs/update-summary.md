## 查核方式

桌面測試實際建立視窗，核對正常生成、計算期間訊息迴圈、GUI／CLI 四檔同位元、來源不變、既有結果保護、壞指紋、輸入內輸出拒絕，以及未取整草稿的明示狀態。既有幾何、25個反例、原生收據一致性和跨平台回歸繼續保留。

本輪原件由新 GUI 重跑離線流程，沒有重新執行 VSTA／CATIA，原生證據仍屬其各自計畫與原程式 SHA。歷史三件九側只回讀存檔 log，不假稱新實測。完整回歸可用 `python tools/verify.py`，產生新的本機逐步結果。

本次 Windows 完整回歸 **13／13 步驟通過**，含CLI／Viewer建置、數學、來源、既有案例、25方法、圖／收據一致性、原開檔測試與新增GUI流程。[當次機器可讀摘要](evidence/update-checks-20261106.json)列出實際步驟、結束碼和耗時；其中的測試耗時不是工程師省時。

## 兩條閱讀路徑複查

- **面試官**：首頁 → 技術地圖 → mixed-cover／arc-ordering → C# 幾何 → VSTA編輯與讀回。能分清來源錯誤、數學可行性、工程可用及轉接一致性；129／165的取捨不包裝成工時百分比。
- **首次讀者**：Create demo → 側別與原支持／推估 → Open output → CAD計畫／驗證狀態 → VSTA手冊。具私有資料者再走Build reviewed case；無資料者不被引導尋找未公開的實件。

這是實作與閱讀路徑的自查，不是外部使用者研究。原先自評漏掉貼面與操作問題的紀錄仍保留，不用高分證明沒有其他問題。
