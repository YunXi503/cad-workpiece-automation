## 後續優先順序

1. **工程正確性**：先由工程人員固定實際接觸帶與接受範圍，再處理橫向側線偏差。目前 lower／left 最大樣點距離 0.698534／1.799857 mm，超過 0.3，不能用補圖取代修正與重驗。
2. **操作閉環**：明確定義手調後的新幾何身分、計畫及驗證流程，再實作並原生驗證；不可跳過目前指紋／讀回防護。完整 GUI 匯入重建另有工作量。
3. **歷史完整性**：建立僅留本機的原程式清冊，人工判讀獨立方法、參數變體及證據；公開通用 ID 對應、狀態及經確認原因，不發布公司原檔。
4. **展示與效益**：在獨立測試 Part 補原生掃描／面同場檢視與保存重開證據；工時改善要同條件對照後才能量化。
5. **發布條件**：作者決定程式授權；持續保留原件資料不公開的重現限制。

本輪沒有新增幾何判定方法、修改原 STL、重跑 VSTA 或改寫舊原生收據。以上未完成項目是可追蹤的後續工作；沒有填成已通過，也沒有依自評分數刪除。
