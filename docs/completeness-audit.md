## 後續優先順序

1. **工程可用與去焊道審看**：確認主要輪廓、肩部、端部範圍，以及難加工焊道是否被適當略過；標記工程師實際需要改的部位。lower／left 的 0.698534／1.799857 mm 是診斷資訊，不單獨否定可微調草稿。
2. **減少人工與接續操作**：補手調後的新幾何身分／驗證及建面接續，避免工程師重新畫整段。保持指紋及正確模型防護，完整 GUI 匯入重建可另改善操作成本。
3. **量測真正效益**：同工件、同起始資料、同可用草稿標準，比較人工投入、總經過時間、剩餘微調及失敗重做；把支持準備成本算入，不以元件數直接推算省時。
4. **歷史與展示完整性**：建立本機原程式清冊與去識別方法對應；補原生掃描／面同場及保存重開證據。原檔不公開。
5. **另行需求**：若有精密製造接觸要求，再確認接觸帶與對應公差。作者決定程式授權；持續保留私有資料的重現限制。

本輪沒有新增幾何判定方法、修改原 STL、重跑 VSTA 或改寫舊原生收據。以上未完成項目是可追蹤的後續工作；沒有填成已通過，也沒有依自評分數刪除。
