# 懸吊臂案例實作紀錄

## 授權範圍與判準

2026-11-05 採用全新尺寸的沖壓鈑金焊接懸吊臂，保留上下殼、變截面、焊道、套筒、複雜剖框及同程式處理不同外形的工程難度。按模型與剖框、幾何處理、原生 VSTA、公開驗證順序完成。

幾何門檻沿用最大 XY 偏差 0.3 mm、取整位移上界 0.05 mm、接點與首尾殘差 1e-7 mm、G1 切向差 1e-7。STL 支持身分另以來源三角面及剖面核對。原生測試以新懸吊臂計畫的輸入雜湊、約束狀態和建面收據為準。

## 事前預測與證偽條件

1. **模型與剖框**。名義輪廓只供產生網格與後驗比對。從完整網格實際求交，應出現上下蓋、圓角、焊道和內孔的交線。若剖框無法呈現這些角色，先修模型。
2. **蓋壁判讀**。從交線的連通與蓋面跨度建立候選，沿蓋端經圓角追到壁支持。若移除生成器標籤後不能產生同一判斷，視為未完成。
3. **多轉折側線**。沿用端部支持、相切線弧、原始與等分點距離及支持移除的概念獨立實作。若跨段 G1 或原公差不通過，保存失敗原因。
4. **尺寸取整**。固定取整後的線長及半徑，調整可行掃掠並重建整鏈。若無閉合根或位移超過 0.05 mm，該版本不進 CAD 合格交付。
5. **原生執行**。使用本次合成計畫在 VSTA 編輯器建置及 F5。外部 COM 診斷與宿主執行各自保存入口，若宿主不可用，記錄實際阻礙。

每階段先完成單一變動的對照，再加入下一階段。結果由真實命令及原生收據回填。

## 實測與修正

| 階段 | 問題、修正與結果 |
| --- | --- |
| 模型與來源 | 主件 28,170 面／714 框，第二件 27,182 面／688 框。套筒剖框有多分量，焊道在交線中形成外凸段。設計圖與剖框圖經實際渲染檢查。 |
| 共端點走訪 | 初版把相鄰面回報的同幾何交線當分支，主件只有少量支持。加入端點核對，走訪時合併重複幾何，來源仍保留。 |
| 工程草稿 | 原始支持與未定各自保存。主件 705 個來源支持／9 個推估，第二件 683／5。以同蓋兩端的參考偏移內插，原始三角面不改。 |
| 多轉折與取整 | 舊單組線弧無法解釋雙轉折。加入中間直線支持分段、局部相切擬合與共線合併，兩件各側均為 6 個實際局部擬合元件合併為 5 個。取整後全鏈通過原判準。 |
| 原生宿主 | 專用測試庫儲存與建置後，使用編輯器開始偵錯命令。兩件各 3 草圖／15 元件／30 有效約束／3 有限延伸面，原生最大殘差分別 6.3553e-14、4.3221e-14 mm。 |
| 原生前置拒絕 | 第一次正確庫執行因舊側別名稱限制而拒絕。只修改通用名稱契約後重跑取得成功收據。較早啟動到其他專案的結果另存本機，沒有拿來充當懸吊臂成功。 |
| 反例與回歸 | 六個懸吊臂案例涵蓋不同外形、漏掃、蓋寬切換、高度及反序。刪除設計標籤後仍能求解；來源高度竄改被拒絕。蓋寬切換保留兩側擬合失敗。 |

原生收據、離線數據與重跑命令見[懸吊臂案例](suspension-arm.md)。
