# 專案時間線、角色與交付

| 階段 | 工程工作 | 公開入口 |
| --- | --- | --- |
| 建立基線 | 重現既有掃描到剖框流程，釐清原始交線與後處理點的身分。角度排序長弦及最長串誤判促成拓撲核對。 | [剖切歷史](engineering-decisions.md#剖切與取線) |
| 探索幾何分界 | 比較固定壁方向、自由圓、單／雙／三弧、剪枝及蓋面選寬。分開看模型可行性、候選覆蓋與物理位置。 | [蓋壁與數值搜尋](engineering-decisions.md#蓋壁與數值搜尋) |
| 轉為工程交付 | 以可微調的線弧草稿為交付，保留可靠支持、缺口及衍生推估。針對凹折回查混蓋來源，再逐側改善可用性。 | [混蓋案例](history/mixed-cover.md) |
| 草圖與建面 | 串接 CAD 前置檢查、Sketcher 約束、求解後讀回及延伸面。分別保存每個幾何版本與原生證據。 | [VSTA](macro.md) |
| 操作與部署 | 將人工選擇、核對與批次流程放入操作員介面，改善設定匯出、內容指紋、重試與 Windows 解壓搬移。 | [重試及搬移](history/resume-integrity.md) |
| 尺寸與驗收 | 將實際線長與半徑取到 CAD 要求精度，離線核對首尾、接點與相切。原生試跑到參考 Part 前置檢查，實際接觸另驗。 | [驗收範圍](verification.md) |

## 貢獻怎麼閱讀

- **我的開發工作**集中在掃描至 CAD 交界的流程串接、來源追查、候選與異常案例對照、線弧草稿驗證、操作員介面與 Macro 開發除錯。作品集逐案附上可讀程式及合成重現。
- **沿用的技術**包括專案原有的插值、取樣和線弧數值核心，以及既有 CAD Automation API。歷史回歸以同版核心做對照，公開示範則用獨立撰寫的核心重現工程概念。
- **工程確認**涵蓋實物位置、套筒排除範圍、板金肩部、候選點及製造驗收。各種確認各有範圍。履歷只引用程式建置、數值檢查、原生結果及其他能追溯的工作。
- **效率改善**從操作步驟、可接續性和減少可編輯段數說明。實際節省工時待量測。
