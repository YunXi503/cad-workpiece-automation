# 歷史貼面完整圖集

這份圖集保留使用者提供的 **18 組編號、59 張 CAD 視埠圖**。使用者確認方法為「程式依選取點自動擬合平面」；原圖逐張以原 bytes 擷取，沒有裁切、改形或重畫。先讀[貼面方法與工程圖解](surface-methods.md)，再按下表展開個別區域。

金色為掃描外形，灰色矩形為局部平面，黑叉為畫面顯示的點記號。這是圖像判讀，不由黑叉反推未保存的精確輸入／剔除集合。金灰交錯含有遮蔽與相交顯示，不能當作量測的接觸面積。

**原圖缺第10組**，保留編號不補造；組號不是工件數、平面數或製作順序。各圖比例與視角不同，不可用像素直接比較尺寸。圖集的 CAD 版次未綁定本庫 Case A 三側計畫，歷史圖不能替代當前計畫的新原生驗收。
