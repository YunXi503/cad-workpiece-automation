## 第二輪複審 B

改由歷史索引 → arc-ordering／short-window → 新GeneralFitting的排程紀錄 → 獨立驗證器 → 驗收表進入，確認不只首頁能讀懂。以候選漏選、錯位置平行短窗、非法來源平面及有限高度反例核對：未定不是無解，XY通過不是三維貼合。從handoff直接找新schema與原件私有轉接，不依賴首頁先備說明。
