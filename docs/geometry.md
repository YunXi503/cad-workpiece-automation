# 計算幾何與誤差驗證

## 從 STL 剖到可追溯支持

對剖面上一個站位 `q` 和單位法向 `n`，先計算三角形頂點有號距離 `d = n · (p − q)`。異號邊的交點參數是 `t = d₀ / (d₀ − d₁)`。共面三角形略過，落在框外的交線裁切。剖切線段保留三角面索引，組串時只因共端點建立連通關係。全域角度排序與選最長串的反例可直接重跑。 [剖切程式](../src/Core/Scan.cs) · [角度排序反例](history/angle-sort.md) · [最長串反例](history/longest-chain.md)

合成件在剖面內找連通、近垂直、能跨過探測高度上下各 0.45 mm 的壁支持。近水平蓋面和孤立斜角保留於剖面證據。多個不同交點標為未定。單站缺口只在同側兩端均有觀測、蓋面標籤一致時取中點，並清楚標記為推估。公開版的蓋標籤來自合成工作設定，歷史方法如何估計蓋壁身分另見[決策檔案庫](engineering-decisions.md)。

## 相切線弧與減段

用首尾支持方向求兩條支撐線交點 `C`。對轉角 `θ` 與半徑 `r`，兩個相切點沿支撐線距 `C` 的距離為 `r tan(|θ|/2)`。先在可行區掃描半徑，再局部縮小步長。候選以原始點及弧長等分點驗證，直線僅量到有限線段，圓弧僅在掃掠範圍內量徑向距離，其餘落到較近端點。 [向量、擬合與重建](../src/Core/Geometry.cs)

公開的 6 → 3 來自合成切窗基準。演算法嘗試合併共線線段或同圓同向的相鄰弧，逐次核對兩組點的最大 XY 誤差。它展示如何讓更少的元件通過相同判準。歷史專案曾用支撐移除後重擬合，該版本的使用範圍見[專案時間線](project-history.md)。

## 實際尺寸取整

取整兩段線長與弧半徑，再在原掃掠角附近用二分法求端到端弦長的根。之後旋轉整鏈讓首尾弦向量對齊。缺乏變號區間時回報不可用，保留擬合階段資料。取整位移以每段相同參數的位移取樣加二階導數界，弧段補上 `(r₀ θ₀² + r₁ θ₁²) / (8N²)`。線段的位移最大值落在端點。 [取整實作](../src/Core/Geometry.cs) · [獨立驗證](../src/Core/Verification.cs)

對沿 Z 延伸的有限面，樣點距離是 `sqrt(dXY² + dZ²)`，其中 `dZ` 是點到有限 Z 區間的距離。這解釋了為什麼 XY 合格仍可能三維超差。報表只以合成已觀測樣點統計。 [高度反例與結果](verification.md)
